# 第一版实施与验收 · 2026-10-08

选定方向是已确认的「对话书页 · 操作工作台」。暖白正文、浅灰项目侧栏、紧凑顶部和输入区，让对话成为主角；此次直接实现 09 模板，不重新探索方向。具体规范见根目录 DESIGN.md。

实现范围与启动方式见 README.md。浏览器的固定数据用于视觉还原，原生端从真实 pi 读取；没有在浏览器中模拟成功生成回复。桌面采用 Tauri + React/Vite；Next.js SSR、扩展安装卸载、会话分叉和安装包发布不在本版范围。

## 模板落实

- Header 保持 40px，会话标题 14px/500。
- 红绿灯位于左侧，折叠入口在侧栏顶部右侧；分隔线后为新聊天/搜索/扩展。
- 项目文件夹组织 session，保留模型入口和正文阅读层级。
- 回复不显示 pi 头像；正文、工具行、diff 与跟进说明使用同一左基线。
- 输入状态连续嵌入右上 border，right:24px；没有 badge。底部工具栏留白 8px。
- 去掉浏览器原生 textarea 缩放手柄，输入按内容增高，最大 240px 后内部滚动。
- 减法保留已确认模板：没有品牌头、pi 头像、重复时间轴状态或四角分散信息。没有发现需要额外删除的功能文案。
