## What's new

- In-app desktop updates with startup checks, background downloads, circular progress, release notes, and signature verification. Restart and install when the workspace is idle.
- A yearly activity calendar and daily token and cost trends, with date-based conversation filtering.

## Improvements

- Faster navigation while preserving drafts, reading positions, settings sections, Git views, and usage filters.
- Skeleton feedback for first visits, immediate switching to visited pages, and stable page titles and command counts.
- Virtualized conversation lists, improved Git navigation and large-file previews, and refreshes after external edits.
- Clearer navigation, selection states, and text contrast in light and dark themes.
- Improved macOS Dock icon appearance.

## Fixes

- Follow System now responds correctly when the computer's appearance changes.
- Corrected conversation removal and file-discard confirmation styles.
- Fixed Git handling for literal filenames, staged renames, and projects opened from repository subdirectories.
- Commit retries now validate the original branch and HEAD, preventing retries against an externally changed state.
- Fixed diff rendering errors when returning to the Git workspace.
- Save the latest workspace before installing an update. Active tasks or failed saves block restart and allow retry after recovery.

## Installation

- The universal macOS DMG supports both Apple Silicon and Intel Macs.
- Install this release manually when upgrading from an older version. Version 0.3.1 enables in-app updates for subsequent releases.
