## 新增

- 支持桌面应用更新：启动时检查新版本，提供后台下载、圆环进度、更新内容预览及签名校验；下载后可在空闲时重启安装。
- 用量页新增全年活跃日历、每日 Token 与费用趋势，并支持按日期查看相关会话。

## 优化

- 优化页面切换：保留会话草稿、阅读位置、设置分区、Git 视图与用量筛选，减少重复建立页面的开销。
- 首次打开页面时提供 HeroUI 骨架反馈，已访问页面直接切换；固定标题与命令数量徽标，减少加载和切换时的闪烁。会话列表采用虚拟滚动，减少长列表的渲染负担。
- 改进 Git 变更浏览、导航分栏与大文件预览，自动刷新外部编辑产生的变化。
- 改善浅色、深色主题的导航层次、选中状态和文字可读性。
- 改善 macOS Dock 图标显示。

## 修复

- 修复选择「跟随系统」后，应用未正确响应电脑明暗主题变化的问题。
- 修复移除会话与丢弃文件确认界面的样式问题。
- 修复含特殊字符的文件名、暂存重命名和仓库子目录场景下的 Git 差异、恢复与提交处理。
- 修复分支提交失败后的重试检查，防止把重试提交接到外部改变的分支状态上。
- 修复返回 Git 工作区时，差异解析结果被错误清理而导致的显示异常。
- 应用更新安装前重新保存工作区；存在运行任务或保存失败时阻止重启，恢复后可重试。

## 安装说明

- 提供 macOS 通用安装包，支持 Apple Silicon 和 Intel Mac。
- 旧版本需要手动安装本次更新；安装 0.3.1 后可通过应用内入口获取后续版本。
