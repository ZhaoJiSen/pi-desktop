# 主题卡片长名称：调研与建议

方向：保留现有缩略图、三列画廊、主题颜色和悬停预览。优先给完整名称提供足够空间，避免自然折行打乱卡片节奏。本轮只调研与提出方案，未修改产品。

现状：弹层最大宽度 536px。三列减去弹层内边距、网格间距、卡片内边距后，名称空间有限；标签右侧的 Check 使用 visibility:hidden，未选中时也占据13px及gap。标签同时保留2.8em高度，所以短名称下方有两行留白，而长名称仍会折行。

研究来源：

- Raycast 官方 Themes 文档 https://manual.raycast.com/themes ：实际查看 Theme Settings 和 Theme Studio 官方截图。主题切换采用名称列表，Studio 左侧列表与中央实际预览分离；借鉴名称区域与状态/预览分离，不照搬为列表。
- Zed 官方 Themes 文档 https://zed.dev/docs/themes ：方向键实时预览、Enter确认。借鉴保留预览和提交的区别；未声称实际操作了Zed应用。
- Obsidian 官方主题目录 https://community.obsidian.md/search?type=theme ：实际查看 Cards 视图，名称与预览独立，较宽卡片提供完整名称空间，另有List视图与搜索。其主题商店规模远大于本项目，无需搬入排序、安装或列表切换。

建议：

1. 弹层初步扩大至约600–620px，最终以最长现有名称的实际渲染为准。
2. 默认三列，按最小可读卡片宽度逐级变为两列、一列，避免在窄视口或放大时挤压文本。
3. 勾选移出标题行，放在预览右上方有底色的小角标；选中边框保留。
4. 名称使用13px单行完整显示，取消固定两行占位，统一预览高度、文字基线和卡片高度。不缩小字号来硬塞。
5. 同系列变体相邻排列，默认不增加分组标题、搜索框或第二层选择。
6. 不把 Catppuccin / Macchiato 改成所有卡片固定两层副标题；它能解决长名，但会重复系列信息并增加视觉层次，偏离用户喜欢的现有效果。

实施前尚未渲染上述新布局，因此尺寸为建议，不是已验收结果。无新增动效、删除文案、产品源文件修改、类型检查或独立评审。

## 实施与验收

已按上述方向实施，弹层宽度620px；卡片最小宽176px，通过auto-fit自动切换三列、两列和单列。名称13px/20px，完整单行，不裁切、不使用省略号；卡片统一106px高，预览64px高。

勾选已移至预览右上角20px圆形角标，使用当前界面主题的ink/paper对比色，保留selected边框。使用绝对定位，不占名称宽度；状态语义继续由HeroUI ListBox的aria-selected提供。

额外修复：HeroUI ListBox对后续项目默认添加4px顶部margin，导致同排首张预览高于其余卡片。网格卡片现统一margin:0，由gap提供间距。删除原有窄屏强制两列覆盖，使最小卡片宽度能在更小视口下生效。

- 第3轮：同上全部通过。
