# 模型与思考强度拆分

## 方向与范围

延续已有 HeroUI 控件和中性表面，将两个不同频率的操作分开：模型入口负责搜索和切换，思考入口直接调节当前模型。没有新增一套视觉样式，也不改变运行时的能力判断。

- 模型面板移除底部强度区，搜索、最近使用和提供商分组保留；选择后关闭（再次点当前模型也关闭）。
- 独立 ThinkingSelector 使用 HeroUI Button / Popover，复用 ModelThinkingControl。296px 小弹层直接聚焦滑块，保留模型信息/深推理提示、恢复按钮和可用刻度。
- 同时只开一个弹层；/model、/thinking 分别打开对应入口。两种保存互相锁定，避免请求交叉。
- 强度按钮按最长可用文案预留宽度；窄栏截断模型名，强度保持全称。非推理模型显示 Off 并禁用强度入口；切换模型继续默认 Medium（或运行时支持的最近档）。

## 动效与减法

保留 HeroUI 浮层展开/关闭和按钮按压反馈；滑块仍用 Motion 短阻尼跟随，按住圆球放大，极高/Max 星点错峰闪动。减少动态效果沿用现有实现。保存时不降低强度文字和触发按钮透明度，键盘焦点在保存后恢复。

移除合并入口中的分隔点、重复等级与模型面板底部强度区。没有新增说明文案；当前模型、当前等级和操作名称继续保留。

## 验证

主 Agent 局部自检 1 轮，未派独立评审。查看实际深色模型弹层、深色思考弹层、浅色窄栏中英文及最长 Extra high 文案；无重叠、溢出和按钮横移。另以实际截图放大 200% 检查文字、刻度和相邻操作，未实测原生浏览器/系统 200% 缩放。

`verify.mjs` 在本地实际 Composer / ModelSelector / ThinkingSelector 上通过 CUA 驱动。`rpc.html` 使用安装目录模型元数据快照、隔离会话存储和模拟 Tauri IPC（保存延迟 650ms）；没有调用真实模型服务。

连续第 2、3、4 轮全部通过（results.json）：

- 两个弹层内容独立、模型搜索和选择关闭。
- 节点点击、连续拖动、按住放大、阻尼跟随、实时等级、只在松手保存一次。
- 按钮/弹层定位稳定、中性背景、保存期间强度文字不闪烁。
- 键盘逐档、端点、等级可访问名称、焦点恢复；星点保持 Motion 动效。
- 保存失败回退、恢复 Medium、刷新后读回。
- Claude 的 Max 与可用刻度、非推理模型禁用、切回 Grok 后默认 Medium 并恢复对应刻度。
- /model 与 /thinking 分别打开独立面板。

初轮验证停在快捷命令的建议选择阶段（第一次 Enter 选择建议），尚未提交；验证脚本改为输入完整命令后通过发送按钮提交，随后连续三轮通过。产品快捷命令行为未修改。

类型检查（src、scripts、tests 三个项目）、全目标 lint 与 diff 空白检查通过；Impeccable 检测无确定性问题，未添加忽略。未运行生产构建/全量测试，未实测原生 Tauri WebView。
