# 命令与能力配置收敛

北极星：同一项原生能力只出现一个管理对象；设置负责全局偏好，命令工作区负责可调用内容。

## 判断依据

- 现有能力目录自动把 Pi 插件命令、提示词模板、技能包装成能力；调用身份相同，差别在于别名、显示名称、固定状态、参数和附加要求。因此不再在设置里复制一份原生命令目录。
- “命令”工作区分为命令与能力管理：插件/模板/技能在原命令详情里配置；内置及自定义能力用同款 SidebarLayout、HeroUI ListBox、Card、SearchField、Switch、Button、Chip 和 Modal。应用设置只保留快捷入口及管理跳转。
- 红框别名原先是普通 small 文本；新布局将它移到详情的“斜杠入口”，使用 HeroUI Chip。列表只保留对象名称和说明。
- 沿用项目的主题变量、SidebarOption、可调侧栏与 ScrollShadow。未另外增加主活动栏图标。

## 本轮改动

1. 空正文且无附件的能力发送，气泡显示发送快照中的能力名称和图标；历史由已有 receipt 关联恢复。消息正文仍为空，隐藏提示词不会混入聊天、导出或标题。旧历史缺少关联信息时显示“已发送请求”。有正文或附件时沿用原展示。
2. 设置布局取消 1200px 居中限制，导航与页面标题靠左对齐；菜单行高 40→36，间隔 4→2，导航与内容间距 36→24。窄窗口仍用顶部导航。
3. 固定项用 Motion Reorder 和专用拖拽手柄；键盘聚焦手柄用上下键排序，读屏宣布结果。仅重排固定项所在位置，不干扰其余项目顺序；启用与否不影响排序保存。
4. 原生命令与配置共用身份（来源、路径、名称），不是按名称模糊关联。设置和命令共享未保存草稿，跨入口不会丢失修改。内置/自定义能力采用左列表、右详情，运行时能力不重复出现在本地能力目录。

## 动效与减法

- 拖拽项轻微放大，邻项通过 transform 弹簧让位；减少动态效果时无放大、过渡时长为零。
- 列表详情120ms透明度/位移；保留既有按钮与弹层反馈。
- 删除平铺列表中每行的固定/开关/更多操作与右对齐别名；操作集中到选中对象详情。取消空分组标题。设置移除独立能力管理分类。
