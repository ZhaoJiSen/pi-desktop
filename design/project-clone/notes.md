# 项目入口与克隆仓库

设计方向：保留现有中性工具界面，用轻量菜单衔接集中弹窗。远程地址 → 本地工作目录 → 项目与会话。

## 交付

- Projects 箭头在文字右侧6px，默认保留占位但隐藏，悬停/键盘聚焦显示，触屏常显。后续按反馈移除多余22px左缩进：标题与导航图标、项目文件夹图标共用左基线，会话保留内部层级。
- 加号28×28px、HeroUI基础8px圆角，悬停和弹层打开时显示现有hover背景。其他侧栏按钮不受影响。
- 加号菜单与粘贴地址快捷项打开约480px的HeroUI弹窗。自动命名、父目录选择、完整路径预览、进度、取消、保留输入重试和克隆后再次打开均已实现。
- 使用本机Git；支持HTTPS、SSH、SCP风格地址。读取既有凭据和SSH配置，不收集密码或令牌。
- 单个原生克隆任务使用独占临时目录，完成后独占重命名，目标已存在（含克隆中途出现的空目录）时不覆盖。取消终止进程组，清理仅限任务自己的临时目录。
- Project类型不变，成功后复用既有项目打开与持久化流程。浏览器预览明确提示桌面端操作，不模拟业务成功。

## 动效与减法

沿用HeroUI弹窗入场、按钮操作反馈和侧栏项目动效；标题箭头与加号反馈120ms，进度区域140ms淡入。状态区域仅在有进度或错误时出现，空状态不预留高度。减少动态效果时关闭新增过渡与动画。

保留对象、保存位置、目标路径、状态和主动作，没有增加品牌图标、大段说明或托管平台选择区，也没有删除必要文案。
