# 统一能力库

北极星：同一入口查找和配置全部可调用动作，分清来源、执行方式与桌面入口。沿用 Commands / Extensions 的左列表右详情、主题和系统字体。

已确认方向：移除双目录页签，完整目录含 Desktop 预置、Pi 原生命令、扩展命令、模板、技能、自定义。类型、来源、状态分开筛选。内置身份只读，插件只配置桌面快捷方式；新增提示词或基于现有能力建立快捷方式。设置保留数量、预览、拖拽排序。

动效：主按钮按压；详情切换 120ms 透明度与小位移；首次进入 200ms。减少动态效果时直接呈现。不新增图片或装饰资产。

## 实际实现

- 原命令入口改名为能力库，移除命令/能力双目录以及常驻第二个保存栏。原 URL 保持兼容；标签和设置管理链接按完整身份定位。
- 同一目录显示 Desktop 预置任务/模式、Pi 系统命令、插件与本地模板/技能、自定义；来源、类型、状态独立筛选，搜索覆盖调用名与来源。包路径/npm身份归插件，独立文件归本地，原始路径始终保留，不凭名称合并资源。
- 使用原 SidebarLayout、SidebarOption、PackageScrollArea 与 HeroUI ListBox/Select/ToggleButtonGroup/Button/Card/Switch/Modal。列表、详情、来源选择器、编辑器和配置控制器分开，删除旧的分裂目录与不再使用的原详情/列表组件。
- 可直接新建提示词能力，或选择现有资源创建快捷方式；原生系统命令不被转换为模型提示词。原始插件身份和逻辑只读，编辑别名、参数及附加要求。内置计划模式的工具限制继续受桥接保护。
- 原位表单一次保存即持久化。内部滚动、固定的编辑保存区以及内侧 2px 焦点轮廓，避免裁切。原生别名参与校验，自定义提示词不能覆盖 /login 等系统入口。
- 单项保存只持久化显式覆盖，不把全部发现的插件默认为永久配置；缺少资源时保留其已编辑配置并标为不可用。启用/固定即时保存，失败恢复原状态；失败的编辑保留内容；跨对象与跨路由编辑草稿留在内存。
- 在桌面端停用和 Pi 插件加载分开表达。停用的标签、手动斜杠调用和原生按钮均阻止继续调用；停用当前持续模式须先经 Pi 回读退出，失败保留实际状态。自定义删除也先处理当前模式。
- 设置继续管理快捷栏开关、0–6数量、预览与拖拽顺序，配置保存与单项编辑分开。既有配置无新必填字段；disabledCommandIds 为可选扩展，旧配置继续读取。
- 窄内容容器和窄窗口使用列表/详情单页切换；返回保持搜索与滚动位置。重复选择当前条目可再进入详情，方向键只浏览，Enter/点击才进入。保持共享分栏宽度，不改其他工作区布局。
- 聊天仍只展示用户正文或空正文任务名，指令保持发送快照独立传输。正文、附件和输入光标逻辑沿用现有链路。

## 减法与动效

删除双页签、让用户去另一份目录寻找的说明、页面级第二次保存，以及原始资源不支持的禁用范围表单。保留实际来源、调用方式、状态与只读边界。

沿用 HeroUI 按压反馈；首次页面 200ms 轻移/透明度，详情与编辑 120ms 淡入小位移，搜索入口 150ms。只新增透明度与变换动画；减少动态效果直接呈现。没有新增图片、渐变、装饰卡片或主题变量。

## 验证

最终连续三轮为第12轮通过、第13轮通过、第14轮通过；逐项记录见 ui-results.json。脚本 verify-ui.mjs 由主 Agent 通过 CUA 执行：

- 156项完整目录与单一入口；插件来源和技能类型筛选。
- 中文新增、原生别名冲突校验、内侧焦点轮廓、单次保存与刷新读回。
- 保存失败保留内容、切换对象保留草稿；开关失败回滚。
- 停用后直接输入别名与 /compact 均被拦截；原生压缩仍只发一次原生请求，停用状态刷新读回。
- 插件参数/附加要求、基于原资源建立快捷方式、资源移除、同名来源冲突，以及删除自定义项保留原始资源。
- 当前计划模式的 Pi 退出回读，以及退出失败不伪造停用状态。
- 快捷栏设置入口、键盘排序和真实指针拖拽。
- 空正文任务气泡与隐藏指令快照分离。
- 480px容器重复打开当前项、方向键浏览、Enter进入详情、返回保留筛选。

初次调试修正了脚本对原生 Switch.checked 的读取方式、搜索框吞掉夹具功能键时的触发位置，以及测试步骤的搜索残留；不将这些脚本假设错误报告为产品缺陷。窄栏中实际发现的挤压、重复选中与键盘进入问题已修正并进入最终三轮脚本。

额外查看：实际应用浏览器入口；浅深主题；长中文名称；480px内容容器；CSS 2倍阅读局部；强制减少动态效果分支。CSS zoom 不等同于操作系统或浏览器原生缩放；未修改用户系统偏好。

类型检查：应用、scripts、tests 三个项目。lint：src/scripts/tests及Vite/Vitest配置。git diff --check。定向设计静态检测未报告发现，未添加忽略。只运行上述检查，未运行生产构建、全量或单元测试；本轮未修改原生代码。

发送、失败与模式状态使用隔离 Pi IPC 夹具及真实生产组件验证，未调用真实模型或实际 review-loop 插件。没有将夹具中的 Plan 工具集合模拟当作原生工具拦截复验；该原生桥接本轮未修改。实际应用入口截图为浏览器环境已有预览目录，未复测原生 WebView；没有录屏能力。
