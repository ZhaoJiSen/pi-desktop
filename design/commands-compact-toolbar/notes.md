# Commands 顶部工具区紧凑化

北极星：命令列表优先，搜索按需出现；保留清楚的来源和当前筛选状态。

## 设计判断

这是本地命令浏览/管理页，主要任务是浏览分类、选中命令、阅读详情。延续当前 HeroUI 视觉和扩展页的工具开关，不重新探索整页风格。无需图片素材，沿用 Lucide 图标。

参考官方资料：

- [Linear Search](https://linear.app/docs/search)：侧栏放大镜进入搜索；当前视图搜索按需出现，Esc 清空。借鉴渐进展开，不引入全局搜索或新快捷键。
- [VS Code Extensions](https://code.visualstudio.com/docs/configure/extensions/extension-marketplace)：搜索和来源/分类过滤组合使用。其市场检索以常驻搜索为中心；这里保留分类常驻，搜索按需展开，更贴合已有扩展页习惯。

## 改动

- 标题与数量成组，右侧搜索、刷新图标同行。28px 点击区域、14px 图标与扩展页工具一致；沿用 HeroUI Button/Tooltip 圆角、焦点和按下反馈。
- 默认收起搜索；展开后输入框34px，与来源 Select 等高。列表从顶部获得更大空间。
- 自动聚焦；清除按钮仅清空关键词。Esc 或关闭按钮清空并收起搜索，返回入口焦点。刷新保留关键词；切换展开状态保留来源筛选。
- 宽栏仍显示胶囊分类，窄栏仍显示 HeroUI Select。
- 展开/收起160ms高度与透明度过渡，可中断；遵循减少动态效果设置。保留原有页面入场和组件按下反馈，未添加装饰动画。
- 未删除对象名称/分类/数量；省去默认占位的一整行搜索框。无新增界面说明文案。
- 未调整命令数据、列表密度、详情、扩展功能或全局快捷键。
