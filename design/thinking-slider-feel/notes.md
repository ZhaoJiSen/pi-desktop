# 思考强度：短阻尼与无闪烁保存

延续用户确认的 Codex 参考方向，主角是白色圆球，颜色只在滑轨。此次修局部手感与状态反馈，组合面板的结构留待用户决定。

## 处理

- 继续使用 HeroUI Slider，保留它的鼠标、触控、键盘与可访问输入。Motion 驱动圆球位置与填充裁剪，共用一个 spring（stiffness 2400 / damping 42 / mass .18）。圆球位置只改变 transform，不再动画 left / width。按住可见圆球放大至 1.16 倍，焦点环和交互区域保持原尺寸。松开吸附实际档位。
- 拖动标题按最近支持等级实时预览；仅松手发一次保存。连续位置、实时标题、已保存值职责分开，拖动不反复调用运行时。修复原 aria-valuetext 仅在跨档时覆盖导致同一档内小数读数的问题。
- 原来选择强度复用整个模型面板的 changing 状态，使模型行、输入和标题同时禁用变淡。现在区分保存强度与切换模型；强度保存仍暂时锁定操作，保留文字透明度，并使用 aria-busy。结果回来后同步已接受档位，失败回退并显示错误。没有给文字添加重新入场、交叉淡化或 shimmer。
- 减少动态效果时直接到位、不放大，星点静止。未新增依赖、未改变模型能力范围和 Medium 默认策略。
- 减法检查：没有新增可见说明、没有删掉判断所需文案，也没有额外装饰。此次没有实施模型/强度拆分。

## 结构建议（供用户决定）

| 方案                           | 作用与代价                                                                                                                                           |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 两个独立入口、独立弹层（推荐） | 模型按钮只打开搜索和模型列表；强度按钮只打开短滑块。任务直接，模型列表不会压住常用调节区。代价是工具栏多一个入口，窄容器需要沿用当前输入区展开规则。 |
| 一个入口、当前合并面板         | 最省工具栏空间，一次打开可调两项；但长列表与强度共享大面板，层级难清晰，调强度总要看到无关列表。                                                     |
| 单个入口、模型/强度分视图      | 空间紧张时折中；多一次切换、发现成本更高，不作为桌面默认。                                                                                           |

拆开的是操作入口，能力关系仍联动：新模型默认 Medium，按支持范围回退；不推理模型隐藏或禁用强度入口。当前不做 Fast 开关，因为本项目运行时未接入独立 Fast 控制。
