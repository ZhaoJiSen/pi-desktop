# Composer 能力标签与快捷配置

设计方向：让当前工作方式可见，提示词留在发送链路。沿用项目现有 Nord/语义主题、HeroUI 控件与 Lucide 图标，不另建视觉体系。

## 已实现

- 快捷入口选择能力，输入框内显示一个持续模式和一个单次任务；标签可查看详情、关闭，插件任务可编辑参数。
- 新设置区支持快捷数量 0–6、开关、固定、排序、编辑、复制、新建、停用、删除自定义项和恢复内置项。
- 应用嵌入 Pi 扩展，通过公开通知通道返回带请求标识的结构化回执。用户输入与隐藏上下文分离；模板和插件命令使用 Pi 原生展开/执行。
- 计划模式实际限定为来源确认的内置 read/grep/find/ls，在调用阶段再次拦截其他工具；退出恢复之前可用的工具，状态跟随 Pi 会话分支。
- 已安装 subagent 工具时，开启计划前通过插件公开状态接口确认后台任务为空；无法确认则拒绝开启。review-loop 缺少 subagent 工具时不可用。
- 分支内保存发送快照及用户消息关联时间，重开、同步、导出不显示模板展开结果。单次指令不会持续注入后续请求。超时先查回执；无法确认的旧请求不会自动重复发送。
- 配置迁移到版本 3；新会话无模式，持续模式由 Pi 回读，失败保留草稿与选择。

## 动效与减法

复用当前弹层动效；快捷点击微缩、标签 150ms 透明度/位移进出，减少动态效果时直接到位。移除“替换草稿/追加草稿”的旧预览流程。仅详情和编辑界面展示提示词，聊天正文不增添配置说明。

## 验证

- `ui-results.json`：主 Agent 最终第 10、11、12 轮连续通过实际生产组件的浏览器交互，覆盖草稿、发送失败、快照重试、隐藏历史、计划恢复与冲突、模板、设置刷新读回、存储失败、自定义命令、换行、模式切换失败、复制/删除/恢复、浅色窄栏、减少动态效果、已接收超时和桥接失效保护。
- `runtime-results.json`：主 Agent 依次三轮通过安装在本机的 Pi 1.3.0；本机模拟模型真实发出 write/bash/plugin_write 请求，验证无文件写入；覆盖后台任务阻止、会话重开/切换、新会话、工具恢复、计划副本仍受限制、隐藏上下文、清理、去重、模板与来源验证。
- 类型检查、lint、Rust cargo check 离线执行；不运行生产构建或全量测试。
- 浏览器页面使用隔离 sessionStorage 和模拟 IPC，但呈现真实 Composer/Conversation/CapabilitySettings/编辑组件；真实 Pi 对接另由运行时脚本验证，没有使用外部模型或真实凭据。
- 未验证打包后的原生 WebView、真实远端模型及实际 pi-subagents 工作流的执行结果；插件依赖检查和工具限制在本机夹具插件中验证。
- 窄屏验证为 380px 内容容器；200% 图为实际截图的放大阅读，不宣称系统缩放验收。
