# Commands 右侧详情对齐 Extensions

北极星：同级详情面板拥有相同的文字层级和空间密度，命令名称与语法继续易于辨认。

## 方向与改动

- 以现有 Extensions 的实际运行画面及计算样式为准，保持扩展页不变，仅调整 src/styles/_commands.scss。
- 标题：从自适应 24–30px 改为 19px / 1.35，字重 550，字距 -0.3px，与扩展详情一致；保留命令的等宽字体。
- 说明正文：15px 改为 13px / 1.65，使用同样的辅助文字色。
- 来源 Chip：11px 字号、24px 高、8px 水平内边距，与扩展一致。
- 区块标签、来源路径、操作说明：11px；动作按钮：12px、32px 高，与扩展的辅助信息和按钮层级一致。
- 用法代码保留 12px 等宽文字，采用扩展详情值信息的字号层级，避免把关键命令降低为辅助路径字号；代码框内边距改为 10px 12px。
- 页面内边距：桌面 22px 24px，950px 及以下为 20px，与扩展相同；移除原来的 800px 最大宽度。
- 说明、用法、来源等区块使用 18px 间距；操作分隔线上方 20px、下方 18px，操作说明与按钮相距 10px。
- 沿用 HeroUI Card、Chip、Button；没有新增图标、装饰、文案或交互，没有删除文字。保留现有切换详情动效，没有新增动效。

- 一轮主 Agent 局部视觉自检，未独立评审：查看扩展参考、命令深浅色、390px 长文与路径换行、实际 CSS 200% 缩放及中文状态。
- 最终 verify.mjs 连续运行三次通过（英文深色、英文浅色、中文浅色），结果见 results.json：标题、正文、Chip、标签和面板内边距与扩展计算样式相同；多类型命令切换后标题和用法对应；900px / 390px 与 200% 无详情溢出；没有页面异常。
