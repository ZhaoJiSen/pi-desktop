# 配色系列

外观在浅色 / 深色之外增加整套配色。默认仍是墨色。另外七套：Gruvbox、Catppuccin、Linear、Nord、Ayu、One Dark、Min Dark。用户写的 grovbox 按 Gruvbox 处理。

每一套同时换纸面、侧栏、文字、线条、主动作、链接、选中、状态和代码色。浅色或深色仍用原来的开关：Gruvbox 用官方浅色 / 深色，Catppuccin 用 Latte / Mocha，Nord 用雪色 / 极夜，Ayu 用 light / dark，One Dark 的浅色是 One Light，Linear 用界面的靛紫而不是宣传色，Min Dark 配 Min Light。圆角、投影、输入区表面和控件形状不动。

## 改动

- `palette` 记在工作区偏好里，写到 `documentElement.dataset.palette`。旧的蓝色、靛蓝等值读不出来时回到墨色。
- 设置 → 外观，配色用现有的单选。色点是每套自己的标志色。浅色 / 深色 / 跟随系统的小预览跟着当前配色走。
- 会话列用侧栏色。墨色下这一列是 `#f7f7f6`，和规范里的侧栏一致。
- 代码色和运行中的文字走变量。墨色仍是原来的代码色；运行中的文字浅色 `#936b14`、深色 `#e1ba63`。发送钮在空内容时仍是半透明。

## 取舍

- 正文、辅助字、链接、状态字和代码色按各自的纸面或代码底做到 4.5:1 以上，焦点环 3:1。因此有些官方色被压深或提亮：Nord 浅色的霜蓝、One Light 的蓝、Catppuccin Latte 的辅助字、Ayu 浅色的语法色、Gruvbox 深色的红。主动作仍能认出是哪一套。
- Gruvbox 浅色按钮用官方橙 `#af3a03` 配白字。深色按钮用 `#fe8019` 配 `#3c3836`，对比约 4.6:1。
- Ayu 浅色按钮是金橙 `#ff9940` 配深字。浅色语法色压深，否则在近白代码底上不够读。
- Min Dark 的深色值没能从主题仓库原文拉下来，用的是近中性灰：纸面 `#1f1f1f`、侧栏 `#181818`、文字 `#d4d4d4`。Min Light 按已核对的工作台色。代码色用 VS Code 默认的深色 / 浅色语法色。
- 文字选区仍是琥珀。红绿灯不跟着配色走。
- 没有改动效。
