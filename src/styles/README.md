# 样式组织

`index.scss` 按固定顺序加载各功能入口。较大的功能使用同名目录存放子模块，根目录的 `_功能.scss` 只负责按顺序 `@use`，例如：

```text
_source.scss              源码面板样式入口
source/
  _panel.scss             面板布局、拖动、工具栏
  _changes.scss           变更列表、分支操作、恢复确认
  _file-details.scss      文件信息、详情导航、切换动画
  _diff.scss              差异视图及第三方组件适配
  _diff-skeleton.scss     差异加载骨架
  _navigation.scss        提示、过滤、历史记录、跳转入口
```

## 功能目录

| 目录                  | 内容                                                             |
| --------------------- | ---------------------------------------------------------------- |
| `capabilities/`       | 能力标签和详情、选择器、编辑表单、图标选择                       |
| `commands/`           | 命令浏览、详情、能力操作、能力库                                 |
| `composer/`           | 输入框、工具栏、附件和状态、提示词、斜杠菜单、窄屏适配           |
| `conversation/`       | 消息和 Markdown、工具调用、差异、工具输出、代码块、会话布局      |
| `onboarding/`         | 引导步骤、可执行文件配置、项目选择和完成操作、安装流程           |
| `packages/`           | 包列表、详情、加载与反馈、导航、筛选和维护、工作区布局、安装状态 |
| `popovers/`           | 浮层基础、项目选择、模型选择、操作菜单、思考强度控件             |
| `settings-workspace/` | 设置布局、能力库、窄屏适配、列表交互和保存状态                   |
| `sidebar/`            | 窗口控件和导航、分区、项目、会话、活动栏                         |
| `source/`             | 源码面板、变更、文件详情、差异视图、骨架、导航                   |
| `usage/`              | 用量概览、会话列表、反馈、窄屏适配                               |
| `utility-views/`      | 工具页共用样式、设置布局、设置控件、命令详情                     |
| `themes/`             | 主题变量与色板，见 [主题说明](themes/README.md)                  |

## 维护约定

- 修改样式时优先找到对应功能的子模块；入口文件不追加选择器。
- 按功能边界拆分，通常保持在 100–300 行左右，避免把无关功能堆回同一文件。
- 保持 `index.scss` 和各功能入口的加载顺序；后加载的规则可能覆盖前面的规则。
- 部分历史覆盖规则仍放在后加载的模块中，以保留现有级联。调整归属时，需同时确认 CSS 输出和界面效果。
- 只在功能入口加载子模块，避免从其他功能直接加载带 CSS 输出的模块，导致输出位置提前。
- 单纯拆分文件时，对比拆分前后的完整 CSS 输出，并执行项目构建；选择器、属性值和规则顺序应保持一致。
